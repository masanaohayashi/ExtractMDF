All musical fixture data was created for this project, not copied from music archives.

tiny.mid: 26-byte SMF with one end-of-track event.
mixed.mid: deterministic SMF with a sequencer-specific meta event containing
pseudo-random bytes (Python Random seed 68000), repeated bytes and repeated blocks.

The corresponding .mdf files were produced using HARPOON's original LZM.X v2.91
from RC291.LZH, invoked as LZM.X -c TEST.MID / MIXED.MID through run68x.
The original executable and run68x are not bundled with this project.
