# 検証結果

2026-10-25 / Apple Silicon macOS / Swift 6.3.2

ユーザーが指定した `_MT32_CM64/_Etc` フォルダのMDF **30個、格納ファイル57個** を、一時フォルダに解凍して比較しました。原本は変更していません。

- Swift版 `lzmtool` と、run68x上で動作させたオリジナルの `LZM.X v2.91 -e` を使用。
- 各MDFごとに、出力ファイル数・ファイルサイズ・SHA-256の集合を比較。
- **30/30アーカイブ、57/57ファイル一致。**
- RCP、CM6、WRDを含む複数エントリの実データで確認。
- ファイル名の同一性はこのハッシュ比較の対象外。Shift JISの曲名・格納名はCLIとGUI表示で別途確認。

SwiftUIの画面からフォルダ追加→保存先選択→一括解凍を実行し、57ファイルの完了表示を確認。GUIが保存した57ファイルのSHA-256も、オリジナルLZMの出力と全件一致しました。

単体テスト8件が成功。元のLZMで圧縮した自作のMIDI2種類を使用。長い繰り返し、遠距離参照、重複参照、複数エントリ、各位置で切断したデータ、不正サイズ・参照・終端、同名保存、シンボリックリンク越しの上書き防止、不正Shift JISコメントの部分復元を検証します。

この比較はサンプルの範囲での互換性を示します。未知のLZM派生版やMDF0以外の形式への互換性を保証するものではありません。
